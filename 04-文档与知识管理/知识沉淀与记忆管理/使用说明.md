# 知识沉淀与记忆管理

将项目背景、偏好、决策和经验整理成可查看、可更新的本地知识记录。

| 项目 | 内容 |
|---|---|
| 分类 | 文档与知识管理 |
| 适合什么时候 | 用户要求记住项目事实、整理经验、回顾决策、管理本地知识库时使用；普通对话不自动收集个人信息。 |
| 需要提供 | 用户要求记住的信息、项目记录或经验 |
| 可以得到 | 本地知识档案、决策记录、经验条目与总结 |
| 能力说明 | 文件记忆适配；不等于系统记忆 |
| 兼容调用标识 | `$knowledge-compound` |

## 直接这样说

> 请用知识沉淀与记忆管理，把今天的关键决策和经验整理到当前项目的知识档案中。

## 核心方法

1. 确认本次要记录或召回的知识范围，优先使用当前项目已有知识目录；没有时可在当前项目创建“知识库”。
2. 分类为偏好、项目、决策、经验、事实，记录日期、来源、适用范围、状态和必要证据。只有经用户表述或材料支持的内容作为事实。
3. 以未来复用价值、关联性和用户获益筛选信息；不自动记录账号密钥、无关私人细节或整段对话。
4. 使用简单Markdown或JSON记录替代缺失的memory_bank.py。读取相关条目后再回答，引用具体文件与条目，不能声称读取了不存在的记忆。
5. 复杂问题可按观察、分析、决策、执行形成闭环；保存最后决定、依据与待办，不保存隐藏推理过程。
6. 用户纠正时核实并更新受影响条目，保留必要的更新记录；支持查看、修改和用户明确要求的删除。
7. 仪表盘和周报来自真实条目统计，不凭空估算节省小时或学习成效。跨会话需要能访问同一目录并读取文件，技能安装本身不创建自动启动钩子或后台服务。

## 安装与能力边界

原版 memory_bank.py 未提供；使用项目内可读文件代替，不承诺全会话自动加载、后台常驻或修改平台原生记忆。

安装包通过结构检查不等于完整功能已经实测。调用时还会检查文档、图像、语音等实际工具。界面名称为中文，内部标识和 SKILL.md、agents/openai.yaml 等必要文件名保留标准格式。
