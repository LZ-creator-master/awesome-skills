## 先看一个真实论文案例

**《Attention Is All You Need》：从方法、公式到数据和源码的中文解读。**

[![Transformer中文解读实际页面截图](assets/attention-case-preview.png)](https://lz-creator-master.github.io/awesome-skills/examples/attention-is-all-you-need/)

- **看方法**：用信息流说明编码器、解码器和注意力各做什么。
- **动手算**：拖动查询向量，观察注意力权重；切换遮罩看归一化结果。
- **查证据**：结果标注原文表号，源码链接固定版本，并保留原文分数差异。

**[直接打开完整案例 →](https://lz-creator-master.github.io/awesome-skills/examples/attention-is-all-you-need/)** · [输入、来源与复用提示词](docs/论文案例说明.md) · [分享介绍文案](docs/论文案例分享文案.md)

本案例是使用 `paper-analyzer` 流程完成的AI辅助解读，非作者官方解读或模型训练复现；互动数据是明确标注的教学算例。[另看纯文本润色对照](docs/润色演示.md)。

## 安装一个技能，开始试用

需要 **Python 3.10+** 和支持本地技能的宿主。默认安装位置面向 Codex；其他宿主请按[安装指南](00-使用指南.md)指定目录。

```sh
git clone https://github.com/LZ-creator-master/awesome-skills.git
cd awesome-skills
python scripts/install.py --skill paper-deaiify
```

macOS/Linux 可将 `python` 换成 `python3`。然后在对话中提供原文：

```text
请使用 $paper-deaiify，润色下面这段论文文字。
保留数字、术语、引用和结论力度，给出修改说明。

[在这里粘贴你的段落]
```

如果找不到技能，请先确认安装目录，再重启宿主。自动选择是否生效取决于宿主。

- **中文使用卡**：每项写明输入、产物和工具依赖。

本库是收藏说明文件的中文兼容整理，非原作者完整工具包。安装不会补齐外部脚本或连接第三方账号；使用前可查看[能力边界](docs/适配与能力边界.md)及[来源与授权](docs/来源与授权状态.md)。

## 维护与验证

```sh
python -m pip install -r requirements-dev.txt
python scripts/validate.py
python -m unittest discover -s tests -v
```

修改技能后需同步 `catalog.json` 中的文件哈希，可运行 `python scripts/update_catalog.py`，再执行校验。详细流程见 [维护指南](docs/维护指南.md)。
