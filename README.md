# 中文实用技能库

仓库：[LZ-creator-master/awesome-skills](https://github.com/LZ-creator-master/awesome-skills) · [自动检查](https://github.com/LZ-creator-master/awesome-skills/actions/workflows/validate.yml)

17 个按场景整理的中文技能，覆盖论文阅读与写作、演示制作、产品需求、文档处理和知识管理。

每个技能都包含中文使用卡、标准 `SKILL.md` 入口、中文界面名称和完整原始资料。本仓库是对所收藏说明文件的中文兼容整理，**不是原作者完整工具包的镜像**。配套脚本和外部服务缺失的地方均已注明。

## 从这里开始

- **按任务选择**：浏览下方目录，打开对应的「使用说明」。
- **本地卡片导航**：下载仓库后，双击 [00-技能导航.html](00-技能导航.html)，可搜索、筛选分类、复制调用示例。GitHub 文件页展示 HTML 源码，不会直接运行此页面。
- **安装**：参阅 [使用与安装指南](00-使用指南.md)，支持 Windows、macOS 和 Linux，安装器只依赖 Python 3.10 及以上版本。
- **了解差异**：查看 [适配与能力边界](docs/适配与能力边界.md) 和 [来源与授权状态](docs/来源与授权状态.md)。

## 安装与调用

下载仓库 ZIP 并解压，或使用以下命令克隆仓库：

```sh
git clone https://github.com/LZ-creator-master/awesome-skills.git
cd awesome-skills
```

然后在仓库根目录运行：

```sh
# 查看可安装的中文名称和内部标识
python scripts/install.py --list

# 先预览，不写入文件
python scripts/install.py --dry-run

# 安装全部17个技能
python scripts/install.py

# 或只安装某个技能
python scripts/install.py --skill paper-analyzer
```

macOS/Linux 可将 `python` 换成 `python3`。默认安装到 `$CODEX_HOME/skills`；未设置该变量时使用 `~/.codex/skills`。支持用 `--dest` 指定目标目录，详情见安装指南。

安装器会在写入前核验文件，遇到同名但不同内容的技能则停止，已有相同版本会跳过。安装本库不会下载原文中提到的额外脚本，也不会自动连接第三方账号。

调用示例：

```text
请使用 $paper-analyzer，以学术型风格分析这篇论文，生成中文解读网页。
```

也可以直接说「请用论文深度解读分析这篇论文」。中文显示名是否出现在选择菜单、自动选择是否生效，取决于宿主应用的技能发现机制。桌面本地安装不等于网页版 ChatGPT Work 的云端安装。

## 如何选择相近技能

| 你的任务 | 优先选择 |
|---|---|
| 读懂一篇论文的方法、公式、实验与局限 | 论文深度解读 |
| 同一篇论文需要词频、引用、播客等多种产物 | 论文多格式分析助手 |
| 找研究漏洞、补实验、完善论证 | 研究批判性评审 |
| 研究、写作、核验、修订连续推进 | 学术论文全流程 |
| 从一句话形成清晰的产品需求 | 一句话需求拆解 |
| 复杂需求逐层细化并建立追踪关系 | 分层需求细化与追踪 |
| 检查已经写好的 PRD | 产品需求风险排查 |
| 画清楚论文的方法与机制 | 论文方法图解 |
| 制作整页图像式论文汇报 | 论文视觉幻灯片 |

## 仓库结构

```text
.
```

整理机器上的旧备份、已安装状态、临时依赖和旧维护脚本不属于发布内容，已通过 `.gitignore` 排除。技能入口保留标准英文标识，面向阅读的文件夹和界面说明使用中文。

## 维护与验证

```sh
python -m pip install -r requirements-dev.txt
python scripts/validate.py
python -m unittest discover -s tests -v
```

修改技能后需同步 `catalog.json` 中的文件哈希，可运行 `python scripts/update_catalog.py`，再执行校验。详细流程见 [维护指南](docs/维护指南.md)。

测试覆盖文件完整性、入口信息、链接及安装器的预览、重复安装和冲突保护，不代表17个业务流程、图像生成、语音或外部研究接口均经过端到端测试。
