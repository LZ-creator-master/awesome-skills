# 围巾哥内容创作套件

将录音、演讲稿或文章改编为演示、访谈、封面或分章书稿。

| 项目 | 内容 |
|---|---|
| 分类 | 演示与内容创作 |
| 适合什么时候 | 内容跨形式改编、演讲稿转演示、访谈策划、封面或分章书籍写作时使用。 |
| 需要提供 | 音频、文字稿、文章、主题或既有幻灯片 |
| 可以得到 | 所选演示、访谈脚本或音频、封面、书稿 |
| 能力说明 | 文本可用；媒体依赖当前工具 |
| 兼容调用标识 | `$content-creator-skill-scarfbro` |

## 直接这样说

> 请用围巾哥内容创作套件，把这份演讲稿改成网页演示和一张16:9封面。

## 核心方法

1. 选择用户实际需要的演示、访谈、封面、书籍模块；多个明确请求都要处理，不默认生成四套产物。
2. 音频输入先检查可用转写工具，不能读取时说明缺口；文本和已有演示提取结构、关键观点、数据、作者语气。
3. 演示模块：选专业商务、创意活力、学术严谨或文艺简约；每页一个观点，生成独立 HTML，用户需要 PPTX/PDF 时使用可用的文件工具并核对输出。
4. 访谈模块：默认主持人与嘉宾两人，按目标时长安排开场、核心问题、追问和收束。先交付结构化脚本；有可用且获授权的语音能力时生成音频。无真实音频时不虚构精确字幕时轴。
5. 封面模块：按用途采用16:9或3:4，记录主题、标题和视觉方向，用当前图像工具生成用户请求的尺寸。
6. 书籍模块：先确定读者、主题、目标字数和章节大纲，再分章撰写与修订，维护术语、人物和事实一致性。案例和数据需有来源，不凭空扩写个人经历。
7. 书稿应有书名页、目录、正文、必要注释和引用；Word 使用真实可用文档能力，检验分页与排版。十万字是可选规模，不是自动产出承诺。
8. 缺失原版脚本时不照抄命令；按需查阅原文对应模块了解细节，保留作者“围巾哥萧尘”的来源信息。

## 安装与能力边界

保留原作者署名；缺少三份参考指南和五个辅助脚本。语音、图像、PPTX、Word 由实际可用工具完成，不承诺自动达到出版质量。

安装包通过结构检查不等于完整功能已经实测。调用时还会检查文档、图像、语音等实际工具。界面名称为中文，内部标识和 SKILL.md、agents/openai.yaml 等必要文件名保留标准格式。
