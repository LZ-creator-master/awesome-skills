# 研究批判性评审

审查研究主张、方法和实验，形成可执行的补充实验、论证和修订建议。

| 项目 | 内容 |
|---|---|
| 分类 | 学术研究 |
| 适合什么时候 | 研究评审、论文批评、实验设计审查、评审后讨论时使用；仅整理摘要时不启用。 |
| 需要提供 | 研究说明、论文、实验结果或评审意见 |
| 可以得到 | 评审报告、结果与主张矩阵、优先改进计划 |
| 能力说明 | 本地评审可用；外部复核有条件 |
| 兼容调用标识 | `$research-review` |

## 直接这样说

> 请用研究批判性评审，检查我的研究证据能否支持结论，并列出优先补充的实验。

## 核心方法

1. 读取研究叙述、方法、关键结果和已知限制，形成自足的评审材料包；只读取与本任务有关的项目记录。
2. 检查逻辑跳跃、贡献边界、对照与消融、数据泄漏可能性、复现信息、统计不确定性和叙事薄弱点，所有判断关联具体证据。
3. 若当前确有用户授权的外部评审工具，可提交必要材料开展独立复核；使用实际支持的配置并记录真实任务标识。工具不存在时直接进行本地评审，明确这一限制，不伪造外部意见。
4. 对关键批评逐一核对证据，接受有依据的意见，对不成立的意见给出反证。提出能解决具体疑问的最小补充实验，资源预算基于用户数据而非凭空估计。
5. 建立“可能结果—可支持的主张—不可支持的主张”矩阵，以及按影响和投入排序的待办项。
6. 默认一轮完整评审加一轮针对性跟进；重大分歧需新证据、建议已稳定或用户范围已满足时结束，不无限自我对话。
7. 保存研究评审报告，含范围、证据、问题、建议、讨论记录和局限；是否更新长期项目记录遵循本次请求。

## 安装与能力边界

原版依赖 Claude Code 中的 Codex MCP 工具；当前未发现这些工具。可做本地批判性评审，不能宣称已完成外部独立模型复核。

安装包通过结构检查不等于完整功能已经实测。调用时还会检查文档、图像、语音等实际工具。界面名称为中文，内部标识和 SKILL.md、agents/openai.yaml 等必要文件名保留标准格式。
