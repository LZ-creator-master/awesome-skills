# 论文降AI味 Skill

## 使用场景

2026 届毕业生面对的真实困境：
- **知网 2025.12 起正式上线 AIGC 检测**，AI 率超 40% 直接打回
- **Turnitin AI Detector** 对 ChatGPT/DeepSeek/文心一言生成的文本识别率 > 95%
- 导师手动扫一眼就能看出"翻译腔 + 排比句 + 破折号"三连

本 Skill 解决：**把 AI 写的论文段落改成"像本科生熬夜写的"**，同时保留专业术语、数据、引用、逻辑链。

## 核心工作流

### 第一步：识别 AI 特征

扫描输入文本，标红以下 7 类特征：

| 特征类型 | 示例 | 改写方向 |
|---|---|---|
| AI 滥用词 | 值得注意的是、综上所述、在当今社会、随着……的发展 | 删除或替换为更口语的连接 |
| 破折号句 | A——B 的结构 | 改为逗号或拆成两句 |
| "不是…而是…"对比 | "这不是终点，而是起点" | 直接陈述去掉对比 |
| 三项排比 | "更高、更快、更强" / "A、B、C三位一体" | 打散成正常并列 |
| 翻译腔 | "被认为是"、"扮演着重要角色"、"在……的基础上" | 中文化 |
| 万能金句 | "这对未来具有深远意义"、"值得深入探讨" | 删除空话 |
| 总分总套路 | 每段"首先…其次…最后" | 打乱段落节奏 |

### 第二步：三级改写策略

**Level 1 词汇替换**（保守，查重风险最低）
- 同义词替换表：见 `references/ai-word-blacklist.md`
- 专业术语保留不动（避免改错）

**Level 2 句式重组**（中等）
- 长句拆短（>40字必拆）
- 主动被动互换
- 语序调整（时间状语前置/后置）

**Level 3 学术化改写**（推荐）
- 加入不确定性表达（"初步认为"、"可能"、"有待进一步验证"）
- 加入研究局限性陈述
- 补充本校/本地案例（降低通用性特征）

### 第三步：分段处理

- **单段≤2500字**：避免大模型上下文丢失导致原意失真
- 按段落边界切分，不按字数硬切
- 保留原有 Markdown/Word 格式标记

### 第四步：输出校验

输出前自检清单：
- [ ] 原意未改变（数据、结论、专业术语一致）
- [ ] AI 特征词数量降至原文 10% 以下
- [ ] 句长方差增大（有长有短，避免机械匀称）
- [ ] 不含"让我们"、"我们可以看到"等口头禅
- [ ] 破折号和省略号用量 < 每千字 2 个

## 使用示例

**输入**：
> 随着人工智能技术的迅猛发展，智能教育正逐步改变传统教学模式——它不仅提升了学习效率，更重塑了师生关系。值得注意的是，这一变革不是简单的工具替代，而是教育本质的深层重构。综上所述，AI 教育具有深远意义。

**输出**：
> 人工智能技术这几年发展很快，智能教育也在慢慢改变传统课堂。学生可以用 AI 答疑、批改作业，老师的角色从灌输者变成引导者。不过这种变化没那么简单，不能只看成换了个工具。从笔者调研的几所中学看，AI 真正影响的是师生之间的互动方式，比如课堂提问频次、作业反馈时长都发生了变化。AI 教育目前还处在早期阶段，后续效果需要更长时间的跟踪观察。

**对比**：
- 字数：原 108 → 改后 186（扩写增加细节）
- AI 特征词：6 个 → 0 个
- 破折号：2 个 → 0 个
- 加入了"笔者调研"、"几所中学"、"早期阶段"等不确定性和个人化表达

## 调用方式

```
用 paper-deaiify 降低这段论文的 AI 味，目标检测率 < 15%：
[粘贴论文段落或上传 Word]
```

高级用法：
```
用 paper-deaiify，Level 2 改写，保留所有数据和引用，添加本校的本地案例
```

## 配套资源

- `references/ai-word-blacklist.md` — 45 个 AI 高频词替换表
- `references/sentence-patterns.md` — 句式改造模板
- `references/discipline-specific/` — 分学科专业词汇保护表（教育学/体育学/法学）
- `scripts/detect-ai-rate.py` — 本地简易 AI 率预检脚本

## 适用人群

- 本科毕业论文（8000-15000 字）
- 硕士论文（3-5 万字，分章节处理）
- 期刊投稿前自检
- 课程大作业

## 避坑提示

- 不要一次性塞超过 3000 字，会丢失上下文
- 改写后务必人工通读一遍，尤其数据和引用
- 降 AI 味 ≠ 降查重，两者策略不同，可配合使用
- 学位论文切勿使用本 Skill 生成"新内容"，仅用于改写你自己写好的初稿
