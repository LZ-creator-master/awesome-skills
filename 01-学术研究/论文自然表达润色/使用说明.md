# 论文自然表达润色

减少论文套话、翻译腔和机械句式，保留原意、数据、术语及引用。

| 项目 | 内容 |

| 分类 | 学术研究 |
| 适合什么时候 | 论文去套话、学术中文润色、句式重组、自然表达改写时使用。 |
| 需要提供 | 用户已有论文段落、Word、PDF 或文本 |
| 可以得到 | 润色稿、重要修改说明与待核实处 |

## 直接这样说

> 请用论文自然表达润色，修改下面的段落，保留全部数据、术语和引用。

## 核心方法

1. 先识别术语、数字、引用和结论力度，作为不可随意变动的内容。
2. 标出空泛连接、冗余排比、翻译腔、重复总结等表达问题；不能仅凭这些文风特征认定作者使用了 AI。
3. 按用户要求选择词汇微调、句式重组或段落重写。长文按完整段落分批，维护术语一致与上下文衔接。
4. 删空话、拆解过长句子、适度改变节奏，以学术清楚和忠于原意为目标。不要机械删除所有破折号、被动句或结构提示。
5. 不编造“笔者调研”、本校案例、访谈、数据或个人经历；不为了显得自然而增加原文没有的结论、局限或不确定性。
6. 对照原文核验数值、引用和论证强度，交付可直接使用的润色稿及必要修改说明。
7. 不承诺任何查重或 AI 检测分数，不把风格词统计当作实际检测结果。原文只用于理解旧版表达策略，检测率、虚构调研示例不沿用。

## 安装与能力边界

缺少词汇、句式、学科参考表和检测脚本；已取消“检测率低于15%”等无法保证的承诺，并纠正示例中凭空添加调研经历的做法。

安装包通过结构检查不等于完整功能已经实测。调用时还会检查文档、图像、语音等实际工具。界面名称为中文，内部标识和 SKILL.md、agents/openai.yaml 等必要文件名保留标准格式。
