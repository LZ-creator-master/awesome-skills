# 论文深度解读

把论文的创新、方法、公式、实验和局限讲清楚，生成便于分享的深度 HTML 长文。

| 项目 | 内容 |
|---|---|
| 分类 | 学术研究 |
| 适合什么时候 | 论文深度解读、论文解析网页、公式和源码对照分析时使用；优先于泛化多格式导出。 |
| 需要提供 | 论文链接、PDF 或全文 |
| 可以得到 | 深度解读网页、来源和代码对应说明 |
| 能力说明 | 方法可用；缺补充模板 |
| 兼容调用标识 | `$paper-analyzer` |

## 直接这样说

> 请用论文深度解读，以学术型风格分析这篇论文，生成中文网页。

## 核心方法

1. 获取全文；arXiv 优先读摘要页和 HTML 全文，无法获取时读 PDF。标记实际阅读范围，不用摘要冒充全文。
2. 查找作者公开代码，区分已发布、待发布、未找到。存在时只读关键源码和配置，关联至少两处方法与实现，记录文件和行号；没有代码时不编造。
3. 提炼核心创新、输入—处理—输出、关键实验、作者自述局限和独立判断。保留公式符号定义及图表编号，解释数据意味着什么。
4. 使用用户选定的故事型、学术型或精炼型；未指定时默认学术型并说明。故事型以问题引入、方法、结果和边界串联；学术型突出推导、实验与证据；精炼型保留摘要、关键创新、数据表和方法图。
5. 生成中文 HTML 长文。需要原版风格细节或 HTML 模板时，查阅 references/原始说明.txt 的“三风格详细要求”和“HTML 输出模板”，但只复用适合当前材料的结构。
6. 公式和图表按内容需要使用，不能为达到原版数量指标捏造公式、引文或结果。引用遵守实际来源许可与引用限制。检查页面可打开、公式可读、图表完整、源码引用准确；外部渲染依赖说明清楚。

## 安装与能力边界

缺少 styles 下五份风格规范与 scripts/generate_html.py；原文已经包含三种风格要求及 HTML 示例，可使用实际可用工具生成网页。

安装包通过结构检查不等于完整功能已经实测。调用时还会检查文档、图像、语音等实际工具。界面名称为中文，内部标识和 SKILL.md、agents/openai.yaml 等必要文件名保留标准格式。
