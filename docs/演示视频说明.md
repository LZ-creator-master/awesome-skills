这段无旁白视频由实际浏览器页面采样录制，包含真实控件操作；字幕是录制时的说明覆盖层，不是产品界面的一部分。为便于观看，镜头按固定帧率组织为30秒，不代表下载、模型调用或完整阅读只需30秒。

| 视频时间 | 画面和操作 |
|---|---|
| 0–5秒 | 导航页选任务，查看安装命令和提示词 |
| 5–8秒 | 打开Transformer基础版 |
| 8–11秒 | 切换进阶版 |
| 11–19秒 | 调整查询、开启遮罩、重置注意力算例 |
| 19–23秒 | 查看固定版本源码对应 |
| 23–27秒 | 查看并复制调用提示词 |
| 27–30秒 | LightGCN组会提纲入口 |

格式：1280×720、10帧/秒、H.264 MP4，无音轨；提供中文字幕和文字脚本。网页播放器不自动播放，可暂停或下载。

可复用录制脚本为 `scripts/record_demo.cjs`，需要Node.js、Playwright与可用的Chromium/Edge及FFmpeg。它仅访问本地预览，逐帧录制，不会调用模型或向社交平台发帖。具体浏览器与编码器路径通过环境变量提供，不写入仓库。
