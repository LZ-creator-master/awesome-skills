# 维护指南

[返回首页](../README.md)

## 单一可发布版本

中文分类中的 `技能包/skill-id/` 是可发布技能的来源；`catalog.json` 记录包路径、中文名称、用途和每个文件的SHA-256。不要把已安装副本或本机绝对路径写回仓库。

## 修改技能

1. 修改相应 `SKILL.md` 和必要参考材料；如改变用途，同步中文使用卡和 `catalog.json` 的描述。
2. 同步 `agents/openai.yaml` 中的中文显示名、简介和调用示例。
3. 原始资料用于来源对照。调整适配行为时优先修改入口，不应悄悄重写原文来消除与原版的差异。
4. 运行 `python scripts/update_catalog.py` 更新文件清单与哈希。
5. 安装开发依赖后运行校验与安装测试：

```sh
python -m pip install -r requirements-dev.txt
python scripts/validate.py
python -m unittest discover -s tests -v
```

自动检查包括17个唯一标识、中文显示名、包内容、文件哈希、维护文档的本地链接，以及安装预览、完整安装、重复安装、选装和冲突保护。

CI配置在Windows和Linux上运行同样检查。本地测试通过不表示GitHub上的CI已实际运行，也不代表外部服务已验证。

## 原始资料与换行

`.gitattributes` 为普通文本统一LF；原始说明保留原始字节，避免换行转换破坏来源哈希。修改来源文件时须明确记录原因，并核对 `original_sha256`。

## 提交范围

本机的维护历史、缓存依赖、旧备份、安装状态、迁移ZIP、Python缓存和凭据文件均被忽略。新建文件后检查 `git status`，只提交与技能使用和维护有关的材料。

不将真实账号令牌、个人路径、实验私有数据或项目记忆放入示例。Issue和PR不要附带未经处理的本机诊断日志。
