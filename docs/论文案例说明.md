## 如何复用

在仓库根目录安装单个技能：

```sh
python scripts/install.py --skill paper-analyzer
```

将以下提示词和论文链接提供给支持该技能的宿主：

https://arxiv.org/abs/1706.03762v7

区分论文事实、教学例子和独立判断。
对关键数字标注章节或表号；遇到来源不一致时保留差异。
若存在作者公开代码，固定提交版本并核对至少两处源码。
生成可独立打开的中文HTML；不要声称复现了未运行的实验。
