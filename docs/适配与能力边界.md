# 适配与能力边界

[返回首页](../README.md)

原始收藏为17份独立Markdown说明，未附完整脚本、模板与引用目录。本文说明中文兼容版保留的核心和未恢复的扩展功能。

## 学术论文全流程

- 核心：统筹选题、研究、写作、核验、评审、修订和定稿，适合从研究到论文的完整任务。
- 能力状态：流程适配；原版完整系统缺失
- 适配与缺口：缺少 academic-paper、academic-paper-reviewer，以及 agents、shared、references、templates、examples 配套文件；本包不能复现原版多智能体、护照恢复和自动审计机制。
- [使用说明](../01-学术研究/学术论文全流程/使用说明.md)

## 论文深度解读

- 核心：把论文的创新、方法、公式、实验和局限讲清楚，生成便于分享的深度 HTML 长文。
- 能力状态：方法可用；缺补充模板
- 适配与缺口：缺少 styles 下五份风格规范与 scripts/generate_html.py；原文已经包含三种风格要求及 HTML 示例，可使用实际可用工具生成网页。
- [使用说明](../01-学术研究/论文深度解读/使用说明.md)

## 论文多格式分析助手

- 核心：从同一篇论文整理文字、词频、引用、网页、幻灯片和播客等多种交付物。
- 能力状态：需媒体工具；原版脚本缺失
- 适配与缺口：原文所列下载、提取、词频、语音、播客、HTML、PPT、引用脚本和 stopwords.txt 均未提供；采用当前可用能力逐项完成，不保证原版批处理链。
- [使用说明](../01-学术研究/论文多格式分析助手/使用说明.md)

## 研究批判性评审

- 核心：审查研究主张、方法和实验，形成可执行的补充实验、论证和修订建议。
- 能力状态：本地评审可用；外部复核有条件
- 适配与缺口：原版依赖 Claude Code 中的 Codex MCP 工具；当前未发现这些工具。可做本地批判性评审，不能宣称已完成外部独立模型复核。
- [使用说明](../01-学术研究/研究批判性评审/使用说明.md)

- 适配与缺口：缺少词汇、句式、学科参考表和检测脚本；已取消“检测率低于15%”等无法保证的承诺，并纠正示例中凭空添加调研经历的做法。
- [使用说明](../01-学术研究/论文自然表达润色/使用说明.md)

- 适配与缺口：缺少 merge_deck.py 及六份参考规范；可用现有演示文稿和 PDF 能力合成。整页图像式 PPTX 不等于可逐字编辑的 PPTX。

## 共通处理

- 补齐可发现的技能入口、中文描述和界面元数据，保留英文内部标识。
- 不再把其他平台的工具名、缺失文件或账号接口当作已安装能力。
- 依据用户实际任务触发，不接管无关任务，不对已经明确的信息反复确认。
- 原文是来源资料，中文入口明确了冲突处理方式。
- 修正不实检测率、虚构调研经历、全会话自动记忆和角色强制接管等规则。
- 业务产物仍需真实工具和材料；格式校验不能证明业务结果质量。
