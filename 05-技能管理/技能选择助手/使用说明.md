# 技能选择助手

根据当前任务，从真正可用的技能中推荐最合适的选项与组合。

| 项目 | 内容 |
|---|---|
| 分类 | 技能管理 |
| 适合什么时候 | 用户明确询问该用什么技能、推荐已有技能或匹配技能时使用；用户直接要求做事时，不把执行任务替换为推荐。 |
| 需要提供 | 任务描述或技能选择疑问 |
| 可以得到 | 简短推荐、适用理由与调用示例 |
| 能力说明 | 文本方法可用 |
| 兼容调用标识 | `$skill-selector` |

## 直接这样说

> 请用技能选择助手，推荐适合把论文做成组会汇报的已有技能。

## 核心方法

1. 理解核心任务、输入、目标产物与约束。
2. 从当前会话真实技能清单、可验证安装记录和中文使用卡中匹配；区分已安装、仅有安装包、依赖未就绪。
3. 优先推荐明确覆盖需求的技能，通常1—3个，最多5个；说明强匹配或辅助匹配，不虚构精确成功概率。
4. 输出中文名称、适用理由、关键限制、兼容调用标识与一条示例。多个技能互补时说明各负责哪个产物。
5. 明确输入名称可直接指向对应技能；无匹配时坦诚说明，使用真实可用的技能安装或插件管理能力处理发现需求，不推荐不存在的find-skills作为必需工具。
6. 单纯推荐任务不执行所描述的工作；若用户同时明确要求选择并执行，完成选择后在授权范围内继续。

## 安装与能力边界

不再假定find-skills已安装；新技能发现和安装使用当前实际可用的安装或插件管理能力。

安装包通过结构检查不等于完整功能已经实测。调用时还会检查文档、图像、语音等实际工具。界面名称为中文，内部标识和 SKILL.md、agents/openai.yaml 等必要文件名保留标准格式。
